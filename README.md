---

# Project Scope

TaskFlow is a modern task management SaaS application developed using the MERN stack. The project helps users manage tasks, boards, deadlines, priorities, and workflow efficiently through an interactive Kanban-style interface.

The application supports task organization, drag-and-drop functionality, deadline tracking, overdue task management, authentication, and responsive UI design.

This project demonstrates full-stack development concepts including frontend development, backend APIs, database management, authentication, and real-time UI interactions.

---

# Features

* User Authentication (Login/Register)
* JWT Secure Authentication
* Drag and Drop Kanban Board
* Task Creation and Management
* Deadline Tracking
* Overdue Task Detection

# Installation Steps

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/taskManagementCT.git
```

## Install Frontend Dependencies

```bash
cd client
npm install
```

## Install Backend Dependencies

```bash
cd ../server
npm install
```

## Run Frontend

```bash
npm run dev
```

## Run Backend

```bash
npm run dev
```

---

# Environment Variables

Create `.env` file inside server folder:

```env
PORT=5000
MONGO_URI=YOUR_MONGODB_CONNECTION
JWT_SECRET=YOUR_SECRET_KEY
```
